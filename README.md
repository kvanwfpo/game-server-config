## 先搞清楚：游戏服吃的是什么资源

绝大多数游戏服务端的负载特征和网站完全相反。它不扛高并发请求，但它是长连接、有状态、地图常驻内存的，而且主循环大多是单线程。

于是四个指标的重要性排序基本固定：

- **内存**：最容易先满的。Minecraft 服务端起服后基础占用约 1–1.5GB，每个在线玩家再吃 200–400MB，加载 Mod 每个再加 50–200MB，世界探索范围越大需要常驻的区块越多。
- **CPU 单核主频**：不是核数。主频越高，tick 越稳。多核只在你想一台机器上开多个服的时候才真正有用。
- **磁盘 IO**：地图加载和存档落盘都走磁盘。低 IOPS 的盘在大地图下会周期性掉帧，这属于"配置明明够却卡"的典型原因。
- **带宽上行**：服务端是数据下发方。Minecraft 每人在线大约占 0.3–0.5Mbps 上行，幻兽帕鲁每个玩家约 0.5–1Mbps，16 人帕鲁服至少要 8–16Mbps。10 人以下的服，5M 上行通常够用。

结论很简单：先按内存定档，再看单核性能，最后补带宽。反着来的话，最容易出现的情况就是堆了一堆核、买了大带宽，进服还是卡。

## 买国内还是买海外节点

国内节点的优势是延迟低，玩家在同城同省，ping 通常个位数到二十几毫秒。代价是域名要备案。

不想备案就走香港，延迟一般比国内高 20–30ms，联机体感上影响不大。日本、韩国、德国这些节点主要适合玩家分布比较散的群体，或者你只是自己测试。

一个实操心法：不用只看"哪里便宜"，先看你的玩家在哪。服务端跟着玩家走，比跟着价格走更划算。

## 这个价位要接受的取舍

说实话，低价位的机器不是没有边界。用之前最好先确认三件事：

第一是 IP。游戏云部分机型走 NAT，和别的用户共用公网 IP，靠端口映射，官方允许自定义开放 15 个端口。对着 Minecraft、帕鲁、饥荒这类只需要一两个端口的游戏完全够；如果你要开一堆不同端口的服务，就得加购独立公网 IP——各机房价格不同，第三方测评里出现过的档位是宁波 100G 高防 IP 30 元/月、温州单线高防 IP 60 元/月，镇江的独立 IP 报过 200 元/个。

第二是防御等级。宁波 100G、镇江 200G 共享、宿迁 150G，这些数字是机房级别的高防，不是每台机器独享。小型服足够，如果被针对性打，还是要考虑更高规格的方案。

第三是合规。国内节点公开联机服务要注意备案和相关规定，这点跟买哪家没关系，是所有国内厂商的共同前提。

如果你的需求是企业级的 SLA 保障和全套技术文档，那大厂依然是更稳的选择。如果只是朋友开黑、小圈子长期服，预算在几十到两三百一个月，这类专门做游戏云的服务商在同等配置下确实能省下不少。

## 服务器开起来之后，这四件事别省

- **白名单和验证**：Minecraft 开白名单加 AuthMe 之类的验证插件，CS2 用密码或 Steam 组限制，能挡掉大部分随机进来捣乱的人。
- **备份**：每天定时打包，存到别的地方去，别备份在同一块盘上。被炸服或者存档损坏时，有备份和没备份是完全两种心情。
- **内存上限**：`-Xmx` 别写满。4G 的机器给 3–3.5G 就够，剩下留给系统和缓存，写满了反而容易触发 swap 卡顿。
- **监控**：htop 看 CPU 和内存、iftop 看流量。模组服卡顿八成是内存或者单核到顶了，看一眼就知道该升配还是该砍插件。

## 几个常见问题

**10 个人玩幻兽帕鲁，买哪一档？** 4 核 8G 起步，人多或者长期运营直接 4 核 16G。帕鲁是这些热门游戏里最吃内存的，别在这省。

**7 天无理由退订真的能用吗？** 官方政策是每个账号限 3 次，自助退订。买机械前先看当期政策页更稳。

**选 Windows 还是 Linux？** Linux（Ubuntu/Debian）资源占用低、教程多，是默认答案。Windows 只有在你完全不想碰命令行的时候才考虑，代价是内存基础占用更高、机器更贵。

**月付还是年付？** 第一次买月付，验证完了再上年付。年付 7 折叠加优惠券的力度确实不小，但前提是你确定这台机器能留得住。
